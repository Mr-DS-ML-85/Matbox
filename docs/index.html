// why matbox

Numeric computing, without the license.

Same vectorized semantics you already know. A runtime you can read, fork, and embed. From a single-binary REPL to a Tauri desktop app and a Python module.

[ ]

N-D complex arrays

One universal type: MxArray of Complex64. Every op is broadcast and vectorized by default. No special cases.

∑

180+ builtins

Trig, linalg (QR / SVD / LU / Cholesky / eig), FFT, polynomials, statistics, strings, regex, cellfun, structfun — the kitchen sink.

λ

Closures & handles

Anonymous functions, function handles, multi-level closures with free-variable capture, and varargin / varargout.

LSP

Language server

Real completions, hover docs, and diagnostics for .mbox files in VSCode, Neovim, or any LSP client.

⚙

C FFI

Embed MATBOX in any C / C++ / Python project via matbox.h. Single header, zero magic, predictable memory.

⛰

Simulink-like sim

Block-diagram solver (matbox-sim) and a WebGL/Canvas graphics backend — interactive plots without MATLAB's runtime.

⚡

Blazing fast

1.5s stress suite. 6.2s for ten 500×500 multiplies. Pure Rust, column-major, no LAPACK dependency.

⎇

AGPLv3 + clean-room

Written from original code. Not derived from MATLAB source. Open source, no telemetry, no phone-home.

// quickstart

From cargo build to eig in 60 seconds.

Install once, then drive it from the REPL, scripts, or your editor.

install.sh 
# clone & build
git clone https://github.com/Mr-DS-ML-85/Matbox
cd Matbox
cargo build --release

# drop into the REPL
cargo run --release

# or run a script
cargo run --release -- run examples/demo.mbox
demo.mbox 
% hello, MATBOX
A = [1 2 3; 4 5 6; 7 8 10]

% matrix arithmetic
B = A.* 2          % element-wise
C = A * A'          % matrix product

% eigendecomposition
[V, D] = eig(A)

% anonymous function & closure
f = @(x) x.^2 + 1
disp(f(3))             % 10

% function def
function r = fib(n)
    if n <= 1
        r = n
    else
        r = fib(n-1) + fib(n-2)
    end
end

disp(fib(10))           % 55
// architecture

Seven crates. One engine.

Clean separation of concerns. Use the whole stack or embed just the core.

matbox-cli REPL and script runner — the matbox binary you call from the terminal.
matbox-lsp Language Server Protocol server. Completions, hover, diagnostics for .mbox.
matbox-core Lexer, parser, AST, interpreter, 180+ builtins. The brain. (325+ tests)
matbox-math Column-major MxArray, LAPACK-free linalg — QR, SVD, LU, Cholesky, eig.
matbox-graphics WebGL/Canvas plotting backend. plot, surf, mesh in the browser.
matbox-sim Simulink-like block-diagram solver for dynamic systems.
matbox-ffi C FFI for embedding — single-header matbox.h, call MATBOX from anywhere.
